# Project 11 – Infra Changes with Branching Policy

## Objective
Demonstrate GitHub branching strategy by creating a feature branch and merging changes through a Pull Request review.

## Branching Strategy
- Base branch: `main`
- Feature branch: `feature/project-11-infra-changes`

## Tasks Completed
- Created a dedicated feature branch.
- Prepared project documentation on the feature branch.
- Will submit changes through a Pull Request.
- Will review and merge the Pull Request into `main`.
